# Where Spatial Resolution Matters for Cooling Demand

Code accompanying the manuscript:

**Where Spatial Resolution Matters for Cooling Demand**

**Shailesh Kumar Jha and Vivek Gupta**

## Overview

This repository contains the Python scripts required to reproduce the analyses, figures, and tables presented in the manuscript.

The study examines when spatial resolution materially affects climate-based cooling-demand estimates over India. It develops a framework linking spatial aggregation error to the curvature of the cooling-degree-day index and unresolved subgrid temperature variability, and evaluates the implications for present-day estimates and future cooling-demand projections.

## Reproducibility

The repository contains only the analysis scripts required for the reported results.

The underlying climate and population datasets are not redistributed here. They should be obtained from their original data providers as described in the manuscript.

Before running the scripts, update the data paths to match the local system.

## Data

The analyses use publicly available climate and population datasets described in the manuscript, including:

- MSWX
- CMIP6 climate projections
- WorldPop
- SSP population data
