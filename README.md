# Where Spatial Resolution Matters for Cooling Demand

This repository contains code accompanying the manuscript **"Where Spatial Resolution Matters for Cooling Demand"** and is intended to reproduce the required analyses, figures, and tables.

The study examines when spatial resolution affects cooling-demand estimates, including spatial aggregation error, the curvature–variance framework, validation of Equation (4), and future cooling-demand projections over India.

Climate, population, and other external datasets are not redistributed in this repository and should be obtained from their original providers as described in the manuscript. For reproducibility, local data paths may need to be adjusted to match your environment.

## Citation

Jha, Shailesh Kumar, and Vivek Gupta. *Where Spatial Resolution Matters for Cooling Demand*.
